### クルマのDNA

自動車のモデルや世代のつながり、設計思想を紹介するメディアです。企画・サイト開発・コンテンツ設計・SEO・運用改善を担当しています。

Next.jsとヘッドレスWordPressを組み合わせ、表示性能や記事管理に加えて、車種・世代を横断して読み進められる情報構造と内部リンクを改善しています。

**主な技術・領域：** Next.js / TypeScript / WordPress / SEO / 情報設計

### ほおじろ通信

バイク・ガジェット・キャンプなどを扱う個人メディアです。WordPressを使ったサイト運営、記事制作、検索流入の分析・改善に取り組んでいます。

利用者が何を調べているのかを捉え、記事とサイトの構成に反映する経験を積んできたプロジェクトです。

**主な技術・領域：** WordPress / コンテンツ企画 / SEO / メディア運営

### 小鍛治探偵事務所

自分で立ち上げた調査事業です。サービスの企画とあわせて、Webサイトの開発、相談導線、集客方法を設計しています。

現在は事業検証の段階で、問い合わせから対応までの流れを整え、実際の需要と運用を確かめています。

**主な領域：** 事業企画 / Web開発 / 相談導線の設計 / 集客・運用改善

### MineSIer

Minecraft内のコンピューターやロボットをJavaScriptで操作し、仮想ネットワークや自動化システムを組み立てるModです。

Java・Fabric・Mozilla Rhinoを用い、ゲーム内でコードを実行する環境や、コンピューター同士の通信、ロボットの制御を開発しています。実験段階のプロジェクトとしてソースコードを公開しています。

**主な技術・領域：** Java / Fabric / Mozilla Rhino / JavaScript / 仮想ネットワーク

### SKALE

法律試験の問題を解く際の推論を、学習者が実行できる手順として整理する研究プロジェクトです。

知識を短くまとめるだけでなく、モデルの構築・学習・実行にかかる時間や、未見問題への対応を検証しています。現在は設計・分析段階で、効果は未実証です。

**主な領域：** 知識構造化 / 推論手順の設計 / 評価方法の検討

## 技術と取り組み方

- **Web開発：** TypeScript・React・Next.jsを中心とした画面とアプリケーションの実装、WordPressを用いたコンテンツ管理。
- **バックエンド：** Go・Node.jsによるAPI開発、PostgreSQL・MySQLを用いたデータ設計。
- **開発環境・運用：** Git・Docker・Linux・Vercelを用いた開発と公開。
- **プロダクトと集客：** 課題整理、要件定義、情報設計、SEO、検索流入の分析、公開後の改善。
- **AI活用：** 調査・設計・実装・コンテンツ制作に生成AIを取り入れ、出力を確認しながら開発と検証を進める。

技術選定では、実装のしやすさに加えて、運用費用や更新の手間も考慮しています。個人で継続して運営できる構成を重視しています。

## 過去の開発：Sutututu

サーキット走行の記録を投稿し、サーキット・レイアウト・車種などで絞り込んで比較するSNSを企画・開発しました。二輪車・四輪車の両方を対象とし、ユーザー認証、記録投稿、検索、リザルト表示などを実装しました。

開発に加えて、現地での告知やWebメディアとの連携、検索流入の改善にも取り組みました。複数回の構成見直しを経験し、運用コストを含めてサービスを設計する重要性を学んだプロジェクトです。

開発時にはNext.js・Node.js・PostgreSQLなどを使用し、それ以前の構成ではReact・Go・Cassandra・Keycloak・Dockerなども使用しました。
